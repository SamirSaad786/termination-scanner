AGENT ARCHITECTURE — 6 AGENTS
AGENT 0
Policy Parser
Reads policy PDF. Extracts rules before data is touched. Sets the standard independently.
AGENT 1
Identity Scanner
Detects repeat employee IDs. Flags rehire policy violations with exact citations.
AGENT 2 ↗ CONSOLIDATED
Concentration Scanner
Manager, location, and department clustering — three lenses, one auditable pass.
AGENT 3
Documentation Gap
Maps each termination against required progressive discipline steps. Flags missing documentation.
AGENT 4
Timing Pattern
Calculates proximity of termination dates to FMLA, ADA, and protected-class timing triggers.
AGENT 5
Synthesis
Assembles upstream outputs into a unified diagnostic brief. Never sees raw data.
REQUIRED · CSV
Termination Records
Upload a CSV using the provided template. Required fields: Employee_ID, Department, Manager_ID, Location_ID, Termination_Date, Coded_Reason, Rehire_Eligible.
OPTIONAL · PDF
Company Policy Document
Upload your termination or progressive discipline policy. Agent 0 extracts your specific rules — rehire limits, required steps, documentation standards.
